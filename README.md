# J.A.R.V.I.S Mobile Edition - Final Fixed

Open `frontend/index.html` in Chrome. On first use, an API-key dialog appears automatically. The key is stored in browser LocalStorage.

Features: Gemini chat, Telugu/English language behavior, LocalStorage conversation memory, image vision, microphone input, text-to-speech cleanup, Enter-to-send, and clear memory.

For public deployment, do not expose a Gemini API key in frontend code; use a backend proxy.
